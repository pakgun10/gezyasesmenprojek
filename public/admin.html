💾 Backup & Restore Data

Backup mengunduh satu berkas JSON berisi seluruh data aplikasi — kelas, murid, kelompok, cabang, kriteria, penilai, nilai projek & senam, berita acara, akun, log aktivitas — termasuk berkas foto (terkode di dalam berkas). Simpan berkas ini di tempat aman; bila aplikasi dipasang dari kosong, berkas ini bisa dipulihkan lewat tombol Restore di bawah.

Restore mengganti SELURUH data saat ini dengan isi berkas backup — data yang ada sekarang akan hilang. Unduh backup data saat ini dulu bila masih diperlukan. Setelah restore berhasil, Anda harus login ulang dengan kata sandi dari berkas backup.
